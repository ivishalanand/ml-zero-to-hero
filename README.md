# Vishal - ML Zero to Hero

A free, hand-picked learning path that takes you from zero to building your own GPT, one topic at a time.

It is made for beginners and college students. You need basic Python and nothing else. Every resource is free: videos, interactive explainers you can play with in your browser, and notebooks you can run without installing anything.

## The path

Follow the topics in order. Each one builds on the one before it.

| # | Topic | What you'll learn | Time |
|---|---|---|---|
| 1 | [Regression](01-regression/) | Predict a number, like a house price. | 1 week |
| 2 | [Classification](02-classification/) | Sort things into categories, like spam or not spam. | 1 week |
| 3 | [Unsupervised Learning](03-unsupervised-learning/) | Find groups and patterns in data with no labels. | 1 week |
| 4 | [Model Evaluation](04-model-evaluation/) | Check whether your model really works on new data. | 1 week |
| 5 | [Feature Engineering](05-feature-engineering/) | Turn messy raw data into columns a model can learn from. | 1 week |
| 6 | [Hyperparameter Tuning](06-hyperparameter-tuning/) | Find the settings that make a model perform its best. | 1 week |
| 7 | [Neural Networks](07-neural-networks/) | The building block behind all of modern AI. | 2 weeks |
| 8 | [Reinforcement Learning](08-reinforcement-learning/) | Teach an agent by trial, error and reward. | 2 weeks |
| 9 | [Natural Language Processing](09-natural-language-processing/) | Get computers to read and work with text. | 2 weeks |
| 10 | [Transformers](10-transformers/) | The architecture behind ChatGPT, Claude and every modern LLM. | 2 weeks |

Times assume about 5 hours a week. The whole path takes roughly 3 months.

## How each topic works

Every topic folder has the same four parts:

1. **Key concepts**: the words you should be able to explain by the end.
2. **Resources**: about 10 links, in the order you should go through them. Usually a short video first, then something interactive, then notebooks with real code.
3. **Mini-project**: one small project with a free dataset. This is where the learning actually happens, so don't skip it.
4. **Want more?**: extra links if you want to go deeper.

## Run any notebook in one click

Most code resources are Jupyter notebooks on GitHub. To run one for free in Google Colab, change the start of its URL:

```
https://github.com/...   →   https://colab.research.google.com/github/...
```

Colab needs a free Google account. Kaggle exercises and competitions need a free Kaggle account. Everything else works with no sign-up.

## Tips for getting through it

- **Type the code yourself.** Reading a notebook feels like learning, but writing it is what makes it stick.
- **Do the mini-projects.** Ten finished projects beat sixty watched videos, and they give you something to show.
- **Don't wait until you understand everything.** Move on when you get the main idea. It makes more sense the second time you meet it.
- **Share what you build.** Put your mini-projects on your own GitHub.
